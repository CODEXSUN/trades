# Project Inventory

## Applications

- `src/platform/api`: Fastify API and composition root.
- `src/platform/web`: React application with one login and one desk.

## Modules

- Platform: user, role, permission, user-role, role-permission.
- Trades: bank-account, deposit, payment, commission.

## Shared Dependencies

- `packages/framework`: backend infrastructure and public module contracts.
- `packages/ui`: React components, layouts, and workspace primitives.

Only repository-root `node_modules` and `dist` directories are permitted.
